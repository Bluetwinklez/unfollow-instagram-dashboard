# Yayın öncesi kalanlar

- Kaynak yeniden dağıtım iznini doğrula.
- Yayıncı adı/destek iletişimini ve herkese açık gizlilik URL'sini tamamla.
- Gerçek Instagram hesabında tek hesaplık işlem ve bağımsız doğrulama denemesi yap.
- npm ci, npm run build ve npm test çalıştır.
- Güncel extension/ içeriğini manifest ZIP kökünde olacak şekilde paketle.
- İzinler yalnızca activeTab, scripting ve storage olmalı.
- Anahtar, gerçek hesap verisi veya log-bridge yapılandırması Git'e eklenmemeli.
